# Presentaciones del curso

Este repositorio contiene `claseN.html`, `index.html`, recursos Reveal.js y `md/claseN.md`. Forma parte del espacio `curso-linux`; el programa, apuntes y seguimiento están en el repositorio hermano exterior. Cuando ese espacio esté disponible, leer `../AGENTS.md` y `../seguimiento/estado-actual.md` antes de desarrollar una clase.

Comprobar el estado Git de este repositorio y preservar cambios previos. Revisar la clase anterior y los criterios de `../contexto/estilo-presentaciones.md`. La exportación `md/claseN.md` representa la presentación aprobada; contrastar contenido y enlaces con el HTML. Mantener `index.html` y los enlaces a laboratorios coherentes. No inferir publicación remota de la vista local.
